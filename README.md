# رعاية مالك

A simple Arabic app for Nashoo to log baby Malik's feeds, diapers and sleep, one-handed, with a true-black night mode.

**Install on iPhone:** open https://stabbler53.github.io/Malik-care/ in Safari, tap Share, then "Add to Home Screen". It opens full screen and works offline.

All data stays on the phone (browser storage). Nothing is sent anywhere. Settings has a backup button.

- `index.html`, `sw.js`, `manifest.webmanifest`: the web app.
- `ios/`: an earlier native SwiftUI version (needs a Mac with Xcode to build).
